# Captain photos — add your 12 images here

Place exactly these files in this folder (`public/players/`):

```text
player1.jpg
player2.jpg
player3.jpg
player4.jpg
player5.jpg
player6.jpg
player7.jpg
player8.jpg
player9.jpg
player10.jpg
player11.jpg
player12.jpg
```

Rules:

- Use the exact filenames above (lowercase, no spaces, `.jpg` extension). The app loads them as `/players/player1.jpg` ... `/players/player12.jpg`.
- Captain 1 in the Organizer Setup uses `player1.jpg`, Captain 2 uses `player2.jpg`, and so on through Captain 12.
- JPG, PNG, or WebP images work. If you use PNG or WebP, rename the file to keep the `.jpg` list above, or update the matching captain's image field in the Organizer Setup.
- Keep each image under about 1 MB and roughly square (portrait photos work best; the UI crops them to fit).
- These files become publicly accessible once the site is deployed (see the security note in the main README), so do not use photos that must stay secret before the reveal.

The Organizer Setup panel shows a preview of every image and warns you about any missing files, so check that panel before your event.
